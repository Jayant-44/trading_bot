# Binance Futures Testnet Trading Bot

A Python-based CLI application to place Market and Limit orders on the Binance Futures Testnet (USDT-M). Built as an assessment task, this bot features robust error handling, secure credentials management, a clean CLI UI, and comprehensive dual-channel logging.

## Prerequisites
- Python 3.8+
- An active [Binance Futures Testnet](https://testnet.binancefuture.com/) account.
- Testnet USDT funds (you can generate these inside the testnet dashboard).
